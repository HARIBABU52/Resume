# Resume — Next.js Starter

Minimal Next.js starter for a resume/personal site.

Getting started

1. Open a terminal in the project root (`d:/code/Resume`).
2. Install dependencies:

```bash
npm install
```

3. Run the dev server:

```bash
npm run dev
```

Files created

- `package.json`: project metadata and scripts
- `next.config.js`: minimal Next config
- `app/`: Next.js app router files (`layout.js`, `page.js`, `globals.css`)
- `pages/api/hello.js`: example API route
